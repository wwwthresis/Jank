# `.jank` project format (version 1)

Little-endian. Header `"JANK" | u16 version | u16 reserved`, then chunks:
`tag[4] | u8 compression (0 raw, 1 deflate) | u32 raw_len | u32 stored_len | u32 crc32(stored) | data`, ending with an empty `END\0` chunk.

Chunks: `META` (name), `ASST` (models, textures, skeletons, emotions), `SCEN` (scene, camera, style), `ANIM` (animations), `LAYR` (optional: scene layers - pictures behind and in front of the 3D scene - and the layer stacks of textures), `LITE` (optional: time of day, sun azimuth, shadow mode, strength, quality and softness; written only when they differ from the defaults; one reserved float field is kept for older files and is always 0). Optional chunks added in build 31031: `EDIT` (Edit-mode polygons of each asset - quads, n-gons, seams, sharp edges - with a fingerprint of the triangle mesh they belong to; ignored when the mesh changed elsewhere), `REFS` (reference pictures: image, placement, size, opacity, front/behind), `EASE` (Bézier easing of each in-between), `IDXP` (indexed-colour textures: palette and one index per pixel). Optional chunks added in build 31036: `LGHT` (lamps: `u8 version | u32 count`, then every lamp as `u32 size | data`, so later versions can append fields; data = id, name, kind (0 point, 1 spot), position, aim in degrees, colour, brightness, reach, falloff, cone, soft edge, flicker, flicker speed, halo, attached object id (0 = none), on/off), `LOOK` (the modern effects of the scene style and of every frame that has its own style, as `u8 key | f32 value` pairs: 1 pixel lamps, 2 tone curve, 3 exposure, 4 bloom, 5 bloom threshold, 6 bloom size, 7 contact shadows, 8 shadow reach, 9 lamp halos, 10 CRT curve, 11 CRT mask, 12 colour fringes; unknown keys are skipped, missing keys keep their defaults). Files without the optional chunks are written exactly as before. Unknown chunks are skipped, so older builds can read newer files that only add chunks. The format version is independent of the application version (see `core/src/version.rs`, `FORMAT_POLICY`). The reference implementation is `core/src/project.rs`.
